Step 1: Find Developer Options on Firestick

The exact menu names depend on your Fire TV model and software version. On many devices, Developer Options must be enabled before you can allow installation from an external source.

    From the Fire TV home screen, open the Settings menu.

  2. Select My Fire TV.

    On some models, highlight your device name and select it seven times to reveal Developer Options. This method may differ on some software versions.

    If your device provides an option such as Install Unknown Apps, select Downloader and enable permission only if you intend to install a file from a source you trust. Menu options vary by device.

Frequently asked questions

What is the IPTV Smarters Downloader code for Firestick?

This page lists 811964, but codes can expire or be changed. Verify the current destination before downloading anything; this page does not guarantee that the code remains active or points to an official source.

Is a Downloader code the same as an app?

No. A Downloader code is a shortcut to a web destination. Downloader opens that destination; the code itself is not the application.

Why can't I find Developer Options?

Some Fire TV software versions hide Developer Options until you select the device name several times in the About menu. The exact steps and available installation permissions vary by device.

Can I install any APK using Downloader?

No. Compatibility depends on the device and app. Download APK files only from sources you trust, and check the destination before installing.
