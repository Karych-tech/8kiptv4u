How to Install IPTV Smarters Player on Amazon Firestick

Even though IPTV Smarters is available on Google Play Store and Apple App Store for Android and iOS devices, Amazon Store does not host it. Therefore, to install it on your Firestick, you will need to sideload it.

Before we begin, make sure that "Apps from Unknown Sources" is enabled. Follow these steps carefully.

⚡ Fastest Method — Enter this code in the Downloader app: 811964 Show me how →

Tip: you can also open aftv.news/811964 in any browser — it goes to the same download.

Step 1: Enable Apps from Unknown Sources

  1. On your Firestick home screen, find the top menu bar.

    Navigate to the far-left menu options and locate the Settings entry.

  2. In Settings, choose "My Fire TV".

    Scroll to find the My Fire TV option and select it using the remote's OK button.

  3. Click "About" if Developer Options are hidden.

    On newer Firestick models, Developer Options are hidden by default. Open the About screen first.

  4. Click on your Fire TV Stick 7 times to unlock Developer Options.

    Use the remote's OK/Play button rapidly 7 times — a "You are now a developer" message appears.

  5. Once Developer Options are enabled, select it from the menu.

    It now appears inside My Fire TV, just below the About option.

  6. Turn ON "Apps from Unknown Sources".

    Confirm by selecting Turn On when the warning message appears.

  7. When you see a warning message, click Turn On.

    This is Amazon's standard disclaimer — it's safe when installing trusted apps like IPTV Smarters.

Now your Firestick is ready to install third-party apps like IPTV Smarters.



Step 2: Install Downloader App

This app allows you to download IPTV Smarters since browsers are not supported for downloads.

  1. Highlight the search icon and type "Downloader".
  2. Select and open the Downloader app.
  3. Enter one of the following URLs:
  • 811964 (Short code — easiest)
  • https://aftv.news/811964 (Short URL)

Click Go and wait for the app to download and install.

Step 3: IPTV Smarters Setup

We recommend setting up IPTV Smarters via Xtream Codes API for better performance and automatic EPG loading.

  1. Open IPTV Smarters and click "Login with Xtream Codes API".
  2. Enter your login details (Username, Password, Server URL).
  3. Select Live TV to start watching channels.

To add EPG, simply click on Install EPG — no need to add URLs manually.

That's it! You have successfully installed and set up IPTV Smarters Pro on Firestick. Enjoy watching your favorite channels with 8kIPTV4U.

If you face any issue, contact us — we're always online to help.

Troubleshooting IPTV Smarters Firestick Installation

Running into problems? These are the four most common errors users hit when installing IPTV Smarters on Firestick — and exactly how to fix each one.

  • Problem: "Parse Error" or "There was a problem parsing the package".

    This means the APK file is corrupted or incompatible with your device. Fixes:

    • Re-download the APK using the Downloader code 811964 — the previous download likely failed midway.
    • Clear Downloader's cache: Settings → Applications → Manage Installed Applications → Downloader → Clear Cache.
    • Check your Firestick OS version — very old Fire OS builds can't run current APKs. Update your Firestick software.

  • Problem: "Apps from Unknown Sources" option is missing.

    On newer Firestick models this setting is hidden by default. Fixes:

    • Go to Settings → My Fire TV → About and click your device name 7 times to unlock Developer Options first.
    • If still missing, go to Settings → My Fire TV → Developer Options and toggle "Apps from Unknown Sources" to ON.

  • Problem: Downloader code not working.

    If entering 811964 shows "Code not found":

    • Double-check you typed the digits correctly — one wrong digit breaks it.
    • Check your internet connection; Downloader needs it to resolve the code.
    • As a fallback, enter the full URL manually: https://aftv.news/811964.

  • Problem: App installs but fails to load / opens to a blank screen.

    Fixes:

    • Force stop the app and reopen it: Settings → Applications → Manage Installed Applications → IPTV Smarters → Force Stop.
    • Clear app cache and data, then re-enter your Xtream Codes credentials.
    • Restart your Firestick (hold Select + Play/Pause for 5 seconds) to reset memory.
    • Verify your IPTV subscription is active — if the server is down, the app will show a blank or error screen.
